💡 Important Concept: Virtual Users (VUs) vs. Real Human Visitors

In load testing, a k6 Virtual User (VU) does not behave like a normal human. A single VU clicks continuously without hesitation. In real life, human visitors pause to read, scroll, and click once every 15 to 45 seconds.

Industry Standard Conversion: 1 concurrent test VU = 10 to 30 real-world active human visitors browsing your website at the same time.

2. Key Findings from the 2,000 VU Extreme Test

During our extreme stress test, the site was subjected to a massive traffic bombardment simulating over 20,000 simultaneous students hammering dynamic course pages, mock exam engines, university directories, and news feeds.

✓
Next.js & Edge Network Resilience Vercel's global CDN successfully routed and absorbed thousands of simultaneous requests per second before dynamic execution limits were reached.
!
Vercel Serverless Function Concurrency Ceiling When traffic surged to 2,000 continuous loops, uncached dynamic SSR routes hit serverless execution queue limits, causing HTTP timeouts.
!
Client Socket / Network Saturation The sheer volume of open SSL/TLS connections caused local network port exhaustion, proving the test reached maximum hardware capability.

3. Actionable Roadmap: How to 10x Current Capacity

To prepare Ahsora Meds Academy for massive nationwide marketing campaigns or major exam result announcements, we recommend implementing these zero-to-low cost optimizations:

1
Enable Incremental Static Regeneration (ISR) on Public Pages Add export const revalidate = 3600; to public routes (courses, universities, scholarships). This caches pages at Vercel's edge, allowing the website to handle 100,000+ concurrent visitors without hitting the backend server.
2
Enforce Supabase Transaction Connection Pooling Ensure all database calls route through Supabase's transaction pooler (port 6543) instead of direct connection (port 5432) to prevent database pool exhaustion under concurrent login surges.
3
CDN Edge Asset Caching Ensure all high-resolution banners, mock test graphics, and course PDFs have Cache-Control: public, max-age=31536000, immutable headers.
